📋 Инструкция: Как увидеть логи перед редиректом

⚠️ Проблема: Консоль очищается при редиректе и вы не успеваете увидеть логи.

🔧 Решение 1: Настройка консоли (РЕКОМЕНДУЕТСЯ)

Шаг 1: Откройте DevTools (F12)
Шаг 2: Перейдите на вкладку Console
Шаг 3: Найдите иконку ⚙️ (Settings) в правом верхнем углу консоли
Шаг 4: Включите опцию "Preserve log" (Сохранять журнал)
☑️ Preserve log
✅ Теперь логи НЕ будут очищаться при переходах между страницами!

🕐 Решение 2: Задержка перед редиректом

Я добавил задержку 3 секунды перед редиректом.
Теперь у вас есть время увидеть логи!
[ReservationsHistory] ===== SCRIPT LOADED ===== [ReservationsHistory] JWT token: EXISTS (605 chars) или NULL [ReservationsHistory] Redirecting in 3 seconds...

🛑 Решение 3: Отмена редиректа

Если хотите отменить редирект:
В консоли выполните:
window.cancelRedirect = true

Это отменит редирект и страница останется загруженной.

🧪 Тестирование

1. Откройте DevTools (F12) на этой странице
2. Включите "Preserve log" в консоли
3. Проверьте что токен есть:
localStorage.getItem('jwt') ? 'TOKEN EXISTS' : 'NO TOKEN'
4. Нажмите кнопку ниже:

Открыть историю резерваций
5. Смотрите консоль - логи должны остаться!
